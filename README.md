# VK Музыка для Teyes CC3L

Android-приложение: вход через ВК, плеер в стиле референса, скачивание треков для офлайна, обновление через облако.

## Как получить APK (GitHub, ничего ставить не нужно)
1. Создайте на github.com **публичный** репозиторий, например `vkmusic`.
2. **Add file → Upload files**: перетащите все файлы из этого архива, нажмите **Commit**.
3. Если папка `.github` не загрузилась: **Add file → Create new file**, имя файла
   `.github/workflows/build.yml`, вставьте туда содержимое файла `build.yml` из архива, **Commit**.
4. Вкладка **Actions** → сборка идёт 5–10 минут → откройте её → внизу **Artifacts** → скачайте `VKMusic-apk`.
5. Распакуйте, положите `app-debug.apk` на флешку, установите на магнитолу (разрешите установку из неизвестных источников).

Если сборка красная: откройте её, скопируйте текст ошибки и отправьте Claude.

## Обновление через облако
1. Увеличьте `versionCode` и `versionName` в `app/build.gradle.kts`, загрузите, дождитесь новой сборки.
2. Создайте на GitHub **Release** (например `v1.1.0`) и приложите к нему `app-debug.apk`.
3. Исправьте `version.json` в репозитории (ссылка на APK, номер версии, список изменений).
4. В приложении: **Настройки → Обновление** → вставьте ссылку
   `https://raw.githubusercontent.com/ВАШ_ЛОГИН/vkmusic/main/version.json` → **Проверить обновления**.

Ключ подписи лежит в проекте (`app/debug.keystore`), поэтому обновления ставятся поверх старой версии.

## Важно
- Музыка ВК работает через неофициальный клиентский ключ Kate Mobile. ВК может закрыть это в любой момент.
- Скачивание идёт, пока приложение открыто. Воспроизведение в фоне зависит от прошивки магнитолы.
